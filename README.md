# 星辉魔法 1.21.1 星能力树查看器

Minecraft 模组 **星辉魔法（Astral Sorcery）1.21.1** 的星能力（Perk）树交互式查看器，数据源自模组源码（v2.0.3），共 364 个节点。

## 功能

- **全树浏览**：拖动平移、滚轮缩放，悬停/点击节点查看详情（属性修改、前置要求、注册名）
- **搜索**：按节点名或属性中文名检索，Enter 跳转定位
- **筛选**：按五星座（生息/甲御/攻烈/摧灭/动势）或属性类型（攻击/防御/生命/移动/挖掘/星能力/特殊能力）高亮
- **模拟加点**：输入拥有的星能力点数、选择根源星座后模拟加点：

## 使用

单文件静态页面，无需构建：直接用浏览器打开 `index.html`，或部署到任意静态托管（GitHub Pages / Cloudflare Pages 等）。
